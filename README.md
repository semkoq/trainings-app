# Trainings-App

Web-App (PWA) für Android: Live-Puls vom Brustgurt (z. B. Garmin HRM 600) per Bluetooth, Zonen, Pulsdiagramm, Trainingszeit – plus Auswertung von .fit/.tcx/.gpx/.csv-Dateien und Trainingsverlauf.

**Öffnen:** https://semkoq.github.io/trainings-app/ in Chrome auf Android → Menü → „App installieren“.

Daten bleiben auf dem Handy (IndexedDB). Sicherung über Profil → „Sicherung speichern“.
